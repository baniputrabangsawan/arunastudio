- clear naming
- predictable architecture
- minimal dependencies
- reusable abstractions hanya saat berguna

Hindari:

- `any` tanpa alasan
- massive components
- duplicate logic
- premature abstraction
- unnecessary state
- excessive client components
- dependency hanya untuk fungsi sederhana

Gunakan Server Components secara default bila cocok.

Gunakan Client Components hanya jika membutuhkan interactivity/browser APIs.
